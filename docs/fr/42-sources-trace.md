# 42. Traçabilité des sources

Ce chapitre examine relier une affirmation à sa référence et à sa date de lecture à partir de docs/SOURCES.md, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

une citation sans contexte peut induire une conclusion trop large. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
