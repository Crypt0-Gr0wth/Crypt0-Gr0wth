# 52. Finalité après reorg

Ce chapitre examine définir quand une observation peut être retenue à partir de prototype/hyperevm_finality_window.py, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

le nombre de confirmations dépend du risque accepté. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
