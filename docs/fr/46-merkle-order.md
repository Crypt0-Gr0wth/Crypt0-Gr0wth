# 46. Ordre d’un chemin Merkle

Ce chapitre examine documenter index, direction et combinaison des nœuds à partir de prototype/zk_merkle_membership.py, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

inverser une direction peut produire une racine différente. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
