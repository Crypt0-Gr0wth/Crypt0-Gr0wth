# 11. Binding du transcript

Ce chapitre documente associer preuve, paramètres et instance à partir de prototype/zk_transcript_binding.py. La lecture suit le code et les documents du dépôt Crypt0-Gr0wth, en distinguant les faits observables des interprétations.

## Point de départ

Le parcours identifie les entrées, les contrôles, l’état produit et les dépendances externes. Chaque conclusion doit pouvoir être rattachée au fichier source indiqué.

## Limite

un transcript réutilisé dans un autre contexte est ambigu. Ce chapitre ne déclare ni test réussi, ni audit, ni aptitude au déploiement.
