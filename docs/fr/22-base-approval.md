# 22. Approbation de transaction

Ce chapitre documente séparer intention, simulation et validation humaine à partir de prototype/base_tx_approval.py. La lecture suit le code et les documents du dépôt Crypt0-Gr0wth, en distinguant les faits observables des interprétations.

## Point de départ

Le parcours identifie les entrées, les contrôles, l’état produit et les dépendances externes. Chaque conclusion doit pouvoir être rattachée au fichier source indiqué.

## Limite

une approbation générale devient une délégation implicite. Ce chapitre ne déclare ni test réussi, ni audit, ni aptitude au déploiement.
