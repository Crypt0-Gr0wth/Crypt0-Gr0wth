# 9. Canonicalisation des entrées ZK

Ce chapitre documente stabiliser encodage, ordre et représentation à partir de prototype/zk_public_input_canonicalization.py. La lecture suit le code et les documents du dépôt Crypt0-Gr0wth, en distinguant les faits observables des interprétations.

## Point de départ

Le parcours identifie les entrées, les contrôles, l’état produit et les dépendances externes. Chaque conclusion doit pouvoir être rattachée au fichier source indiqué.

## Limite

deux formes visuelles peuvent signer des octets différents. Ce chapitre ne déclare ni test réussi, ni audit, ni aptitude au déploiement.
