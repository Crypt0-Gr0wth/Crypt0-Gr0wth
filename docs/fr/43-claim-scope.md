# 43. Périmètre d’un claim

Ce chapitre examine définir exactement ce que la preuve établit à partir de GUIDE-STARK-SNARK.md, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

un claim vrai hors périmètre reste inutile. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
