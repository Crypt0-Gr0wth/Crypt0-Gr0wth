# 44. Entrées du vérificateur

Ce chapitre examine séparer format, instance et décision du vérificateur à partir de prototype/zk_verifier_boundary.py, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

une entrée bien formée n’est pas forcément légitime. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
