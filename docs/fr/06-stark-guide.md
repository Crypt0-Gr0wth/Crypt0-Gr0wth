# 6. Parcours STARK

Ce chapitre documente situer AIR, transcript et vérificateur à partir de GUIDE-STARK-SNARK.md. La lecture suit le code et les documents du dépôt Crypt0-Gr0wth, en distinguant les faits observables des interprétations.

## Point de départ

Le parcours identifie les entrées, les contrôles, l’état produit et les dépendances externes. Chaque conclusion doit pouvoir être rattachée au fichier source indiqué.

## Limite

une intuition cryptographique ne constitue pas une preuve. Ce chapitre ne déclare ni test réussi, ni audit, ni aptitude au déploiement.
