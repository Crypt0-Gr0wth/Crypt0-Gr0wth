# 49. Contexte d’action Hyperliquid

Ce chapitre examine lier marché, compte, côté et taille au hash à partir de prototype/hyperliquid_action_hash.py, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

un hash court ou incomplet permet une confusion d’intention. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
