# 47. Bornes d’un range claim

Ce chapitre examine rendre explicites borne basse, borne haute et inclusivité à partir de prototype/zk_range_claim.py, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

une borne implicite crée une ambiguïté de sécurité. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
