# 3. Sources officielles

Ce chapitre documente organiser les références primaires et leur portée à partir de docs/SOURCES.md. La lecture suit le code et les documents du dépôt Crypt0-Gr0wth, en distinguant les faits observables des interprétations.

## Point de départ

Le parcours identifie les entrées, les contrôles, l’état produit et les dépendances externes. Chaque conclusion doit pouvoir être rattachée au fichier source indiqué.

## Limite

une référence ne prouve que son périmètre. Ce chapitre ne déclare ni test réussi, ni audit, ni aptitude au déploiement.
