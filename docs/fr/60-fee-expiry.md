# 60. Expiration d’un devis de frais

Ce chapitre examine lier snapshot, marge et deadline à partir de prototype/base_fee_market_snapshot.py, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

un plafond de gas ne remplace pas une politique métier. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
