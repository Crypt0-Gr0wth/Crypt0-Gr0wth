# 12. Adhésion Merkle

Ce chapitre documente vérifier chemin, index et racine attendue à partir de prototype/zk_merkle_membership.py. La lecture suit le code et les documents du dépôt Crypt0-Gr0wth, en distinguant les faits observables des interprétations.

## Point de départ

Le parcours identifie les entrées, les contrôles, l’état produit et les dépendances externes. Chaque conclusion doit pouvoir être rattachée au fichier source indiqué.

## Limite

un chemin valide pour une autre racine ne prouve rien. Ce chapitre ne déclare ni test réussi, ni audit, ni aptitude au déploiement.
