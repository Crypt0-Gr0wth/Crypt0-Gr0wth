# 59. Provenance multi-étapes

Ce chapitre examine conserver origine, transformation et décision finale à partir de prototype/base_provenance.py, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

perdre une étape rend la conclusion invérifiable. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
