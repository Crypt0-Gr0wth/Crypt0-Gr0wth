# 45. Rejeu d’une preuve

Ce chapitre examine lier preuve, instance et contexte d’utilisation à partir de prototype/zk_transcript_binding.py, dans le parcours source-grounded de Crypt0-Gr0wth. Il sépare les comportements observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les exemples servent à rendre la lecture reproductible sans prétendre constituer un composant de production.

## Limite

une preuve valide ne doit pas changer de domaine sans contrôle. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
